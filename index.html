01 · O conceito

O que é uma API?

API significa Interface de Programação de Aplicações. É uma forma organizada de um programa solicitar recursos ou informações a outro programa, seguindo regras definidas.

01

Imagine a situação

Seu site precisa descobrir qual cidade corresponde a um CEP. Mas ele não tem uma base de endereços.

02

Em vez de guardar tudo…

Seu site consulta um serviço que já oferece essa informação. A API define como fazer o pedido.

03

Os dados chegam

O serviço responde com informações que seu código pode ler e apresentar na tela.

Ideia principal: a API não é a tela do aplicativo. Ela é uma interface de comunicação que permite ao seu programa acessar funcionalidades ou dados oferecidos por outro sistema.
02 · Por trás da tela

Como a informação viaja?

Nesta atividade, vamos usar uma API da web. A sequência abaixo mostra o caminho de uma consulta simples.

01Você digitaum CEP no site
02Seu código pedeusando fetch()
03A internet levao pedido ao serviço
04A API respondecom dados em JSON
05O site mostraa cidade e o endereço
HTTP: conjunto de regras para troca de mensagens na webGET: tipo de pedido usado para consultar dadosJSON: formato de texto organizado para representar dados

Por enquanto, basta reconhecer essas três palavras. Nosso foco é entender a API e fazer a primeira consulta. Outros tipos de requisição, como POST, ficam para uma próxima aula.

04 · Mãos ao código

Agora é você
quem programa.

Vamos criar, no Windows, um arquivo HTML que consulta a API e mostra o resultado. Não precisa instalar Flask, Python ou extensões.

PASSO 01

Abra o VS Code

Crie uma pasta chamada meu-primeiro-api no computador e abra essa pasta no VS Code pelo menu Arquivo → Abrir Pasta.

PASSO 02

Crie um arquivo

Na pasta, crie um arquivo chamado aluno.html. Esse nome é importante: a extensão .html indica uma página web.

PASSO 03

Copie e cole o código

Use o botão Copiar código abaixo. Cole no arquivo aluno.html e salve com Ctrl + S.

PASSO 04

Execute no navegador

Abra a pasta pelo Explorador de Arquivos do Windows e dê dois cliques em aluno.html. Faça sua primeira consulta.

Código completo do projeto

<!DOCTYPE html>
<html lang="pt-BR">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Meu primeiro projeto com API</title>
  <style>
    body { font-family: Arial, sans-serif; background: #0b1023; color: #f5f7ff; margin: 0; min-height: 100vh; display: grid; place-items: center; }
    main { background: #18213d; border: 1px solid #344269; border-radius: 20px; padding: 32px; width: min(440px, 85vw); box-shadow: 0 20px 70px #0005; }
    h1 { margin-top: 0; }
    p { color: #c5d1e9; line-height: 1.6; }
    label { display: block; margin: 22px 0 8px; }
    input { width: 100%; box-sizing: border-box; padding: 13px; border: 1px solid #61739f; border-radius: 10px; font-size: 18px; }
    button { background: #77f2d1; color: #091b27; border: none; padding: 13px 20px; border-radius: 10px; font-size: 16px; font-weight: bold; cursor: pointer; margin-top: 14px; width: 100%; }
    button:hover { background: #a4ffe5; }
    #resultado { margin-top: 20px; background: #0f1730; border-radius: 12px; padding: 18px; line-height: 1.7; min-height: 55px; }
  </style>
</head>
<body>
  <main>
    <h1>🌐 Meu primeiro projeto com API</h1>
    <p>Digite um CEP e descubra como uma página conversa com outro sistema para buscar informações.</p>

    <label for="cep">CEP (8 números)</label>
    <input id="cep" placeholder="Ex.: 01001000" maxlength="9" value="01001000" inputmode="numeric">
    <button id="buscar">Consultar API</button>

    <div id="resultado" role="status" aria-live="polite">O endereço aparecerá aqui.</div>
  </main>

  <script>
    const campo = document.getElementById('cep');
    const botao = document.getElementById('buscar');
    const resultado = document.getElementById('resultado');

    async function consultarCEP() {
      const cep = campo.value.replace(/\D/g, '');
      if (cep.length !== 8) {
        resultado.textContent = 'Digite um CEP com exatamente 8 números.';
        return;
      }

      resultado.textContent = 'Consultando a API...';
      botao.disabled = true;

      try {
        // 1. Envia um pedido de informação à API
        const resposta = await fetch(`https://viacep.com.br/ws/${cep}/json/`);
        if (!resposta.ok) throw new Error('Falha na consulta.');

        // 2. Converte a resposta JSON em um objeto JavaScript
        const dados = await resposta.json();
        if (dados.erro) {
          resultado.textContent = 'CEP não encontrado.';
          return;
        }

        // 3. Mostra na tela os dados recebidos da API
        resultado.textContent = `${dados.logradouro || 'Logradouro não informado'} — ${dados.bairro || 'Bairro não informado'}, ${dados.localidade}/${dados.uf}`;
      } catch (erro) {
        resultado.textContent = 'Não foi possível consultar. Confira sua internet e tente novamente.';
      } finally {
        botao.disabled = false;
      }
    }

    botao.addEventListener('click', consultarCEP);
    campo.addEventListener('keydown', (evento) => {
      if (evento.key === 'Enter') consultarCEP();
    });
  </script>
</body>
</html>

Professor e alunos: o mesmo arquivo aluno.html também acompanha este material, caso prefiram abri-lo diretamente no VS Code. O JavaScript está dentro do próprio HTML, para facilitar o primeiro contato.

O que o código faz? fetch() pede dados à API; resposta.json() lê o JSON; e resultado.textContent apresenta a informação na página. Essas são as três partes que você deve localizar no código.
